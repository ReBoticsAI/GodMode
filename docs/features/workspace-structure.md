# Workspace structure

![workspace-structure in GodMode](/features/workspace-structure.png)


GodMode organizes work as anatomy:

1. **Department**: a region of the body (for example Work, Life or a client project)
2. **Division**: groups work inside a region
3. **Page**: a surface you open and use

New workspaces start with **no departments**. Ask Intelligence to grow the first region and pages, or use **Structure** once you have content to rearrange.

Personal items (Calendar, Tasks, Bank, Vault, Wiki) live outside the department tree in the sidebar.

See [[structure]] for the Structure editor details.
