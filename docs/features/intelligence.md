# Intelligence

![intelligence in GodMode](/features/intelligence.png)


**Intelligence** is the built-in **platform agent**. It is the self-expansion engine: create pages, agents, tasks, wiki articles, scaffold and install plugins, and run cross-cutting platform work from chat.

## Where to open

Chat panel → agent picker → **Intelligence**

## What it is not

Intelligence is not the product name. **GodMode** is the Control Center / OS; Intelligence is the guide and builder agent.

## Agent notes

- Prefer Intelligence for platform setup, structure, coding/plugins, and cross-cutting ops.
- Use Digital You for persona, personal judgment, and stand-in voice ([[digital-you]]).
- Department agents own scoped structure nodes ([[agents]]).
- Self-expansion loop: workspace tools → `scaffold_plugin` → build/install → Marketplace when sharing packs ([[plugin-pipeline]], [[marketplace]]).
